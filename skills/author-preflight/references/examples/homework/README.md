# Чем проверить ДЗ: четыре примера для обсуждения

Подборка для команды курса. Это варианты, а не список обязательных проверок. Начинай с вопроса: **какое различие проверка должна заметить?**

| Что хотим увидеть | Комплект | Где граница проверки |
|---|---|---|
| Функция выполняет контракт | [Копия настроек](function-contract/README.md): условие, заготовка, тест. После изменения вложенного поля в результате исходник остаётся прежним. | Тест проверяет результат и независимость объектов, не конкретный синтаксис. |
| Интерфейс ведёт себя как нужно | [Поиск](browser-behavior/README.md): условие, страница, заготовка логики, браузерный сценарий. Свежий ответ остаётся видимым после запоздалого. | Это не доказательство фактической отмены запроса. |
| Студент применил нужный приём | [Перехват записи](implementation/README.md): условие, заготовка, наблюдение и чтение реализации. | Нужное слово в исходнике не доказывает, что выбранный механизм работает. |
| Студент получил результат и может его объяснить | [Имя файла сборки](manual-evidence/README.md): условие, запускаемая заготовка, шаблон ответа. | Один вывод команды не показывает, что студент понял причину. |

Для новой задачи можно взять один подход, сочетать несколько или выбрать другой. Инструменты из примеров не задают инфраструктуру ПФР.
