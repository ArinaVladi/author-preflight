# Проверка поведения интерфейса: результаты поиска

**Условие.** В [заготовке приложения](starter.mjs) допиши `bindSearch`. Форма запускает поиск через уже переданную функцию `search`. После отправки нового запроса предыдущий запрос больше не должен менять результат, даже если он завершится позже. Способ выбери сам; физически отменять запрос необязательно. В этой задаче имитируются только успешные ответы.

**Файлы:** [страница и управляемые ответы](starter.html) · [заготовка логики](starter.mjs) · [браузерный сценарий](check.md). Страница использует модули: открой её через локальный HTTP-сервер, например `python3 -m http.server 8000` из этой папки, затем `http://localhost:8000/starter.html`.

**Заметка автору.** Очерёдность ответов задаётся руками, без настоящего API и ожидания таймеров. Проверка не требует определённого API для отмены и не доказывает, что старый запрос был отменён.
