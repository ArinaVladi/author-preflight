# Браузерный сценарий

1. **Обычный случай.** На свежей странице отправь `мак` и нажми «Ответ для „мак“». В области результата должно появиться `мак`.
2. **Различающий случай.** Перезагрузи страницу. Отправь `мак`, затем `маяк`. Сначала нажми «Ответ для „маяк“» и проверь, что в результате `маяк`. Затем нажми «Ответ для „мак“»: в результате по-прежнему должно остаться `маяк`.

Решение, которое при любом завершении запроса обновляет экран, пройдёт первый сценарий, но не второй.
