# Проверка контракта функции: копия настроек

**Условие.** В `starter.mjs` реализуй `changeColumns(settings, columns)`. Она возвращает настройки с новым `panel.columns` и сохраняет остальные поля. Исходные настройки не меняются. Панель в результате независима от исходной: последующая правка её полей не меняет исходную панель. В этой задаче у панели только скалярные поля; независимость остальных вложенных полей не требуется. Не меняй имя экспортируемой функции.

**Файлы:** [заготовка](starter.mjs) · [условия проверки в коде](check.test.mjs). После реализации запусти `node --test check.test.mjs` из этой папки.

**Заметка автору.** Первый тест проверяет результат и исходное число колонок. Второй запрашивает то же число колонок, а потом меняет заголовок в результате. Так обнаруживается попытка вернуть общую панель, когда значения и без копирования совпадают. Тест не требует конкретного синтаксиса копирования.
