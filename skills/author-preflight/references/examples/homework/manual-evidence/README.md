# Ручная проверка: что влияет на имя артефакта сборки

**Условие.** В этой мини-задаче сборка уже написана. Запусти `node build.mjs`, повтори запуск без правок, затем поменяй текст в `src/message.txt` и запусти сборку снова. Сравни имена файлов, которые напечатала команда. Объясни, почему повтор без изменений даёт то же имя, а изменение содержимого — другое имя. Команду выполняй из этой папки.

**Файлы:** [скрипт сборки](build.mjs) · [исходный файл](src/message.txt) · [шаблон ответа](RESULTS.md). Папка `dist/` создаётся при запуске, её сдавать не нужно.

**Заметка автору.** Сверь три фрагмента реального вывода и объяснение связи имени с содержимым. Объяснение «сборка создаёт случайное имя» не подходит, даже если два разных имени получены. Один скриншот или один вывод не показывает, что студент сравнил нужные случаи. Это маленькая модель сборки, а не шаблон инфраструктуры ПФР.
