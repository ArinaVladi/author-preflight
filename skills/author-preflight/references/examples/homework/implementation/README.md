# Проверка реализации: реакция на запись свойства

**Условие.** Реализуй `observeSettings(settings, onChange)` в [starter.mjs](starter.mjs). Верни объект, через который вызывающий может читать и менять настройки обычным синтаксисом. При изменении значения уведомляй `onChange(key, value)`; повторное присваивание того же значения не должно вызывать уведомление. Входные настройки — обычный изменяемый объект со строковыми ключами и простыми значениями.

В этой задаче **обязательно перехвати запись с помощью `Proxy`**: цель — отработать перехват операции над объектом, а не спроектировать альтернативный API. Если цель другой задачи — только поведение, не переносите это ограничение.
