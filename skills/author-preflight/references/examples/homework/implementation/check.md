# Что проверять

- **Поведение.** Создай объект из `{ theme: 'light' }` и запиши аргументы каждого вызова `onChange`. Чтение `state.theme` даёт `light`. После `state.theme = 'dark'` чтение даёт `dark`, журнал содержит одну запись `['theme', 'dark']`. Повтор той же записи не добавляет вызовов. Установи новый ключ: `state.compact = true`, и проверь запись `['compact', true]`.
- **Как сделано.** Открой `starter.mjs` с решением. Убедись, что возвращаемый объект — именно прокси, а перехват записи и решение об уведомлении находятся в его обработчике `set`. Наличие слова `Proxy` в комментарии или в неиспользуемой ветке не засчитывается.

Обычный объект с отдельным методом обновления не выполнит поведенческий контракт. Объект с геттером и сеттером для заранее известных полей может воспроизвести часть поведения, но не удовлетворяет требованию к реализации. Ручное чтение здесь дополняет наблюдение за поведением, а не заменяет его.
